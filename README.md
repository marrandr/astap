# hamarino.io

**Hamarino** est une plateforme fermée aux journalistes.

Ils y partagent une information reçue, leurs collègues la confirment ou la contredisent avec des preuves, puis l'auteur décide lui-même de la publier ou non.

---

## Prérequis

- **Système Linux**
- **Docker Compose**

## Lancement

À la racine du projet, exécuter :

```bash
docker compose up --build
```
